# Sales_Analysis_Report

# PROJECT OVERVIEW
This Power BI dashboard provides an interactive analysis of sales performance using dynamic visualizations and KPIs. The dashboard helps users understand sales trends, customer behavior, regional performance, and overall business growth through easy-to-understand charts and maps.
The project demonstrates data visualization, business intelligence, and dashboard development skills using Power BI.

# FEATURES
 Sales trend analysis using line charts
 Region-wise sales visualization with maps
 Category distribution using pie & donut charts
 Funnel analysis for business insights
 KPI cards for quick performance tracking
 Interactive filtering and drill-down analysis
 
# TOOLS ABS TECHNOLOGIES USED
Power BI Desktop
Data Visualization
Business Intelligence (BI)
DAX (Data Analysis Expressions)
Data Cleaning & Transformation
